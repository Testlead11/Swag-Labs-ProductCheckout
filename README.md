 SauceDemo E-Commerce Automation Framework

 Project Overview

This is a web automation framework developed using Playwright, TypeScript, Cucumber BDD, and Page Object Model (POM).

The framework automates key e-commerce workflows of the SauceDemo (Swag Labs) application, including user login, product selection, adding products to the cart, cart validation, checkout, and order confirmation.

It uses reusable page objects and utility methods to improve code readability, maintainability, and reusability.

- User Login
- Product Selection

- Checkout Process
- Order Confirmation

Installation and Execution

Clone the repository:
git clone https://github.com/Ajitham21/Swag-Labs-ProductCheckout.git

Install dependencies:

npm install

Execute tests:

npx cucumber-js


 Project Architecture

The framework follows the Page Object Model (POM), with separate feature files, step definitions, page classes, and reusable utility methods.
